**簡単な説明**（80 文字以内）

```
タックルで倒して、こぼれ球を奪い取れ！ラグビーの「ジャッカル」を体験する3Dゲーム。追いかけて、止めて、ターンオーバー！
```

**詳しい説明**

```
ナイター照明に照らされた満員のスタジアム。相手のボールキャリアが走ってくる。
タックルで倒し、こぼれたボールを奪い取る――ラグビーの「ジャッカル」を、全20プレーで体験しよう。

■ 選手Aで、相手を止めろ
・相手が向こうへ逃げたら「おいかけろ」。ダッシュで追いつき、前タックルで足元に飛びつけ
・相手がこっちへ向かってきたら「とめろ」。目の前で左右にステップしてくるので、かわした側へ左／右タックル
・早く飛び込みすぎるとかわされる。後半はフェイントも入ってくる
・相手がトライラインに近づくと、スタンドのチアホーンが鳴り響く

■ 選手Bで、こぼれ球を奪え
・タックルが決まると、相手に並走していた選手Bに切り替わる
・ボールを持った選手は、倒れたらすぐボールを手放さなければならない。こぼれた楕円球が転がってくる
・相手のサポートより先にボールに触れればジャッカル成功、ターンオーバー！
・後半は楕円球がイレギュラーバウンドして、途中で向きが変わる

■ 味方選手の背中越しの3D視点
・満員のスタンド、ゴールポスト、レフリー、両チームの選手を見ながらプレー
・タックルの瞬間はスローモーション
・右上のミニマップで、選手とボールの位置がわかる

■ ジャッカル成功で大歓声と花火
・太鼓と手拍子の応援、タックルが近づくほど大きくなるどよめき
・ジャッカルを決めるたびに、笛と大歓声と花火
・反応が速いほど高得点。5連続ジャッカルごとに花火が増える

■ かんたん操作
・左下の円形カーソルで移動、右のボタンで前／左／右タックルとダッシュ
・選手Bは移動とダッシュだけ。ボールに触れれば自動で奪う
・自信がないときは「ナビ」をオンに。タックルが届く瞬間とボールの転がる先を教えてくれる

■ その他
・「草ラグビー」から「伝説のジャッカラー」までの称号
・スコアと称号を友だちにシェア（ナビあり／なしも表示）
・失敗したプレーは、広告を見てやり直せる（1ゲーム5回まで）
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

さあ、キックオフ。20プレー、全部ボールを奪えるか？
```
